# 开盘指标（竞价判断 + 博易云浮层）

每天 20:59 / 8:59 集合竞价一出结果，在博易云 4×4 价差看板的每个格子上贴：

- **✅ ▲ ❌**：这根针大概率整根开到 / 开到一部分 / 是假的（○ 没针，？ 不判断）
- **色块「重 / 打 / 小 / 关」**：按两年回放的手数表，一眼看这格上不上手数
- **首 / 半**：猜的第一次真实成交价差、首笔半

开盘后 1 分钟自动消失。全部是脚本按规则算的，不调用 AI。规则详见 [开盘tick/说明.md](开盘tick/说明.md) 的「竞价判断」一节。

**只是线索，不是买卖建议。**

## 怎么装、怎么更新

把 [安装说明.md](安装说明.md) 交给你电脑上的 AI 助手（Claude Code、Codex 等），说「照这个装开盘指标」。
以后有新版本，跟 AI 说「更新开盘指标」，它会运行 `更新.ps1`。每次改了什么见 [更新记录.md](更新记录.md)。

需要：Windows、博易云、Python 3.13、自己的快期账户（天勤 TqSdk 取行情用）。
